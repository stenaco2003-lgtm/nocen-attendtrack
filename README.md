# AttendTrack — NOCEN Music Department

Semester Attendance Management System for the Department of Music,
Nwafor Orizu College of Education, Nsugbe, Anambra State.

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Go to vercel.com and import the repository
3. Vercel will detect it as a React app automatically
4. Click Deploy
